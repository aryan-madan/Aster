# Aster 0.2.0

A major update to everyday browsing, workspace organization, and browser extension support.

- Added customizable workspaces, with an option to share site data across workspaces.
- Added import for bookmarks, browsing history, and passwords from supported browser exports.
- Added screenshot and eyedropper tools, plus dedicated Downloads and History views.
- Added browser extension support, including extensions from the Chrome Web Store.
- Added site permission and privacy controls, including ad and tracker blocking.
- Added browser help, keyboard shortcuts, and search in Settings.
- Improved tab, download, history, and extension reliability, and refined browser controls.
