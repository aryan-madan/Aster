## Aster 0.2.0

A major update focused on everyday browsing, workspace organization, and browser extension support.

### Highlights

- Organize tabs into workspaces, customize each workspace, and reuse a site-data container across workspaces while keeping their tabs and history separate.
- Import bookmarks, history, and passwords from supported browser exports.
- Use built-in screenshot and eyedropper tools, plus dedicated Downloads and History views.
- Install and manage browser extensions, including extensions from the Chrome Web Store, with improved extension settings and reliability.
- Manage site permissions and privacy controls, including ad and tracker blocking.
- Find browser help and shortcuts from the macOS menu bar, and search Settings.
- Improved tab, download, history, and extension reliability, with refinements to the interface and browser controls.

### Compatibility and installation

- macOS 26 or later; Apple Silicon (arm64) only.
- This app is not signed with a Developer ID or notarized. On first launch, Control-click `Aster.app`, choose **Open**, then confirm.
- The 0.1.0 app used a different bundle identifier. It cannot update in place to this release; install 0.2.0 manually.

### Updates

Sparkle checks for updates daily and can install signed releases automatically. The update feed is hosted at [aster.aryan.am/appcast.xml](https://aster.aryan.am/appcast.xml); release downloads are hosted on GitHub.
